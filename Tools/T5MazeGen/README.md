# T5MazeGen — T.Stage5 생성기

`Assets/Docs/TStage5RunnerRedesign.md`가 SSOT. Unity 밖에서 도는 순수 Python이라 빌드에 안 들어간다.

## 지금 쓰는 것 (G단계 — 문 색 배치)

| 파일 | 역할 |
|---|---|
| `t5doors.py` | 10x10 격자 **문 180개의 색 배치** 생성 + 인원별 전수 검증 → `t5doors.json` |
| `t5doorsemit.py` | `t5doors.json` → `t5doors.txt`(에디터 빌더용 평문) + 격자 미리보기 |
| `t5gen.py` | **검증기 `min_switches()` 때문에 남긴다.** 미로 생성부는 폐기분 |

```bash
python t5doors.py            # 시드 탐색 → t5doors.json
python t5doors.py --seed 7036
python t5doorsemit.py        # → t5doors.txt + 미리보기
```

### 색 규칙 — T5에 Common은 없다 (2026-09-20)

열 수 없는 색은 전부 **벽**이다. 둘이 벽이 된다 — **이번 판에 없는 색**(들고 있는 사람이 없다)과
**러너 색**(러너는 1층이라 2층 패드를 밟을 수 없다). 그래서 n인이면 벽은 **(5 − n)색**이고,
검증은 러너가 누구인지까지 포함해 **28가지를 전수**로 돌린다(배치가 대칭이 아니라 러너에 따라 답이 다르다).

seed 7036 실측 최소 전환: **4인 12~13 · 3인 13~14 · 2인 14~15 · 솔로(흑백만) 27**, 도달 불가 0건.

### 합격 기준 (`t5doors.py` 상단 상수)

- 최소 색 전환 — **4인 12 이상**, 3인 10 이상, 2인 8 이상 (인원·러너 전수)
- 솔로(흑 ∪ 백 동시 개방) 도달 가능 + 최단 25~45칸
- **흑백만 쓰면 20전환 이상** — 안전망이 비싸야 고유색을 쓴다
- 오답 가지 4칸 이상 6개 · 고유 4색 각각 의도 경로에 2회 이상 · 색당 문 18~45개

### 만들면서 실측으로 드러난 것 (코드 주석에 근거 있음)

1. **격자 기하가 하한을 정한다.** (0,0)→(9,9)는 최소 18수. 한 색으로 L칸을 달릴 수 있으면
   전환은 대략 18/L이라, 2칸짜리 사슬이 깔려 있으면 무엇을 그리든 9~10전환 길이 생긴다.
   시드 뽑기로는 12를 못 넘어서 **`repair()`가 싼 길의 사슬을 끊는 방식**으로 간다.
2. **복도는 양방향이다.** 오답 가지를 목표 반대로 뻗어도 러너가 먼 끝에서 뿌리로 타면 전진이다.
   뿌리 반경 안에 똬리를 틀게 묶어야 지름길이 안 된다.
3. **최소 전환은 구간 수 S를 못 넘는다.** 의도 경로가 언제나 S짜리 길이기 때문이다.
4. **없는 색을 Common으로 합치면 2인에서 스테이지가 사라진다** — 문 180개 중 89개가 한 묶음이
   되고 최대 성분이 24칸이라 전환 5회에 골인한다. `MISSING_IS_WALL`이 그 스위치다.
   같은 이유로 **러너 색도 Common이 아니라 벽**이다(2026-09-20).
