## 3. 조임 **[확정: 개념]**

**원상 복구는 T1·T3만.** T.Boss는 페이즈 때.

벽이 주기적으로 압박. 외치면 **원상 복구**. 복구 후 다시 조여듦.

| 판 | 조임 | ColorWall | AdvancingWall |
|----|------|-----------|---------------|
| T1 초출 | **좌우**만 | **고유색** | 양쪽 |
| T3 복습 | 좌우 + **위아래** | **흑/백** 초출 (고유는 복습) | 양쪽·위아래 |

패드(Door_3)와 조임은 다른 장면. 볼더·Spike는 압력.

안 함: T4·T5·T.Boss에 지금 원상 복구, 계속 고함으로 벽 고정, T1에 고유+흑백+위아래 한 번에.

코드: 응원 → 시작 위치 원상 복구 없음. 새 RPC 없음.

## 5. 바닥 안개 **[확정: 개념]**

식도의 두 번째 일 = 바닥을 가림. M 닫힘 암흑(시야 전체)과 다름 — **바닥만**. 벽·플레이어는 보임.

초출 **T2**. 복습 **T4**. T5·T.Boss는 지금 안 붙임.

바닥이 안개로 안 보인다. 외치면 걷힌다. 한 외침 = 한 창. 창이 끝나면 다시 깔린다.

걷혔을 때 = **그 순간 챌린지 상태의 바닥** (회색 타일, 이미 개방된 Pioneer 색, 복도 바닥). Memory 미리보기 정답을 다시 켜지 않음.

T2 = 타일이 곧 판. T4 = 복도 바닥을 보고 달려야 함. T5는 캐릭터 추적이라 기본 안 씀.

2인: 한 명이 외치지 않으면 바닥이 안 보인 채로 남는다. 이속만으로는 타일·복도를 못 읽는다.

안 함: 미리보기 Safe/Trap·색 경로를 다시 보여주기, 계속 고함으로 안개 고정, 화면 전체 암전, T5·T.Boss에 지금 붙이기.

코드: 안개·걷힘 없음. 새 RPC 없음.
