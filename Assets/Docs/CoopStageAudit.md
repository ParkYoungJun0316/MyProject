### H.3 버린 제안 (다시 꺼내지 말 것)

- FFA / 팀 생존 폐기
- 5스테이지 채우려고 판 늘리기, 보스에서 신기 초출
- NPC·대화·길 헤맴·글 읽기로 플레이타임 벌기
- 첫 클리어 고유 콘텐츠를 3시간으로 짜기
- 팀 응원 +2힐 / 120초를 시계로 쓰기
- Drop·함정 피하기로 시간 벌기
- 계속 고함 (Vosk는 한 단어 트리거). 창 중 재외침으로 연장
- 조임 원상 복구를 T4·T5·T.Boss에 지금 붙이기
- 안개로 Memory 미리보기 정답을 다시 보여주기
- T5·T.Boss에 지금 안개 붙이기
- ColorWall을 동시 고유 두 벽 필수 멈춤으로 T3 2인 게이트 만들기
- T4 넉백·낙사를 2인 게이트로 만들기

M·T 개별 버린 목록은 각 문서 H.3.

### H.4 코드

`CheerService` 팀 = Heal·120초 **폐기됨**. `ITeamCheerRevert` + Warning 창. 입 닫힘·침·혀 **됨** (플레이 확인 2026-09-04). ColorTile 점수제 코드 됨(M.Stage3 에디터 할당 남음). 수면 아트는 슬롯만 비움. T 조임 원상 복구·안개 걷힘은 **아직 없음**. 새 RPC 없음. NGO 챌린지 축(`NetworkDesign` §11B) 유지.

`MinigameDesign.md`와 충돌하면 **감사 문서가 이김**. 팀 응원 **효과·쿨**이 `CheerSystemDesign.md`와 충돌하면 **이 맵 + M/T 문서가 이김**. RPC·투표·그래머·개인 버프는 `CheerSystemDesign`.

## 4. 2인 테스트 **[확정]**

**둘이서 이 판을 하면, 한 명이 빠졌을 때 막히는 순간이 있나?**

접속 종료가 아니다. **그 판의 목표를 한 사람 몸·입력만으로 끝까지 해낼 수 있느냐.**

| 결과 | 하는 일 |
|---|---|
| **있다** | 그 **장면**은 남긴다. 위 함정만 의심 (버킷 C) |
| **없다** | 판을 고친다. 새 게임이 아니라 **판정**을 2인 기준으로 (버킷 B). 챌린지가 없으면 입/식도 장면 한 개 (버킷 D) |

| 들어감 | 예 |
|--------|-----|
| 미니게임·챌린지 | SideSplit, ColorTile, SequenceRing, Grid, PioneerPath… |
| 스테이지 박자 | T1 패드·문, T1·T3 **조임 원상 복구**, T2·T4 **안개 걷힘**, M1 패드+문, **팀 외침으로 바이옴 되돌리기** |
| 안 들어감 | 함정 피하기, **개인** 응원 버프, 각자 칸 밟기만 (할당량·흑백 없이), **좁은 통로에서 비켜주기만**, T3 ColorWall 잠깐 멈춤, T4 넉백·구멍 낙사·패드→Door 길(각자 생존) |

스테이지 전체가 매 초 막혀야 하는 게 아니다. **판마다 그런 순간이 한 번은 있으면** 통과.
