# rough-estimate — 대강 계산 먼저

1. **실측 기준 + 배수로 답한다** — 사용자 플레이 결과(예: "4인 2초에서 낙사 0")를 기준점으로 두고 곱셈 몇 줄로 "대략 N배 / N초" 수준으로 답한다. 식을 보여 준다.
2. **가정을 적는다** — 추정에 쓴 값(시간·속도·칸 수·인원)은 어디서 왔는지(문서·코드·실측·가정) 표시한다. 가정이면 가정이라고 쓴다.
3. **인원은 지정한 것만** — 인원별 비교가 필요 없으면 사용자가 말한 인원만 본다.
4. **시뮬은 승인 뒤** — 정밀 시뮬이 필요하면 "스크립트 돌리면 N분, 뭘 알 수 있음, 한계"를 말하고 승인을 기다린다. 보정이 안 맞으면 오래 붙잡지 말고 중간 보고한다.
5. **스크래치는 프로젝트 밖** — 임시 계산 스크립트는 세션 스크래치 폴더에 두고, 만들기 전에 "레포 밖 임시 파일"이라고 미리 말한다. `Assets/` 에 넣지 않는다.
6. **결정은 문서로** — 사용자가 값을 정하면 `Assets/Docs/` 의 해당 문서 절에 적는다. 튜닝값이 Inspector 값이면 사용자가 에디터에서 바꾼다(체크리스트 제공).
