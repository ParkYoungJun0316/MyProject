# mcp-edit — MCP 로 에디터 직접 수정

전제: 이 대화에서 사용자가 1번 목록을 보고 허락했다 (승인어: 수정해·고쳐·진행해·만들어·적용해). 이전 대화의 허락은 이어지지 않는다.

1. **바꿀 것을 먼저 적는다** — 오브젝트 → 컴포넌트 → 값(전 → 후) 목록을 보여 주고 승인을 받는다.
2. **열린 씬 먼저 본다** — 대상 씬이 에디터에 이미 열려 있고 dirty(미저장 변경)면, `OpenScene(Additive)` 가 그 열린 씬을 그대로 돌려줘 사용자의 미저장 작업까지 같이 저장된다. dirty 면 멈추고 사용자에게 저장/버리기를 묻는다.
3. **수정** — 목록에 적은 것만 바꾼다. 하는 김에 다른 걸 건드리지 않는다. 플레이 중이면 하지 않는다.
4. **저장 뒤 diff** — 씬·프리팹을 저장하고 `git diff --stat` 과 해당 파일 diff 를 읽어 **의도한 변경만** 들어갔는지 확인한다.
5. **잡음은 스크립트로만 지운다** — UI.prefab RectTransform 잡음(씬 저장 때 수십~백여 줄)이 섞이면 `.unity` 를 손으로 고치지 않는다. `scene-noise` skill 대로 검사 결과를 보여 주고, 허락받은 뒤 `node Tools/SceneNoise/strip-scene-noise.js --apply <씬>` 을 실행한다.
6. **렌더 확인** — 게임 뷰 스크린샷을 `Assets/Screenshots/` 에 찍어 눈으로 확인하고 보고한다.
7. **보고** — 바꾼 목록 / diff 요약(잡음 몇 줄 포함) / 스크린샷 경로 / 안 된 것.
